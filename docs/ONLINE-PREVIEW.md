# Преглед онлайн без локална инсталация

За постоянен сайт и всекидневни редакции използвай [Cloudflare Pages и Pages CMS](CLOUDFLARE-PAGES-BG.md). Описаният тук Codespace е само незадължителен частен преглед за разработка; не е необходим за управление на публикувания сайт.

Сайтът не е публикуван. Pull Request не е сливан. Следните варианти се стартират от собственика, когато реши.

## Препоръчано: GitHub Codespaces с частен порт

Този вариант отваря работната версия в браузъра, без инсталиране на Node.js на компютъра. Не създава Cloudflare сайт или публичен deployment. Предварително е добавена `.devcontainer/devcontainer.json` с официален Node.js 24 образ, автоматично `npm ci`, стартиране на Astro и пренасочване на порт 4321.

1. Влез в GitHub и отвори [работния branch](https://github.com/Dido-hub-create/dido-website/tree/feat/dido-v0-1).
2. Натисни **Code → Codespaces → Create codespace**. Ако GitHub показва „New with options“, избери branch **feat/dido-v0-1**, личния си акаунт и **2-core** машина. Не създавай средата от `main`, където промените още не са слети.
3. Изчакай подготовката. Node.js и зависимостите се инсталират в облачната среда, а сайтът се стартира автоматично.
4. Отвори **Ports → 4321 → Open in Browser**. Остави **Port Visibility: Private**. За този адрес е необходим вход в GitHub; не го променяй на Public.
5. Разгледай началната страница, останалите раздели и оригиналната публикация. В инструментите за разработчици на браузъра можеш да провериш ширини 320, 390, 768 и 1440 px.
6. След прегледа избери **Stop current codespace**. Можеш да изтриеш самата временна среда от [списъка Codespaces](https://github.com/codespaces), без да изтриваш хранилището или branch-а.

Ако прозорецът не се отвори автоматично, в терминала на Codespaces изпълни:

```sh
npm run dev -- --port 4321 --background
```

Провери статуса с `npx astro dev status`; диагностични логове — `npx astro dev logs`. Не са необходими локален терминал, домейн или платен хостинг. В тази задача Codespace не е създаван; конфигурацията е подготвена, но самото ѝ стартиране в GitHub още не е проверено.

### Безплатната квота

Личните GitHub Free акаунти включват 120 core-hours и 15 GB-month месечно; 2-core среда използва 2 core-hours на час. Това е квота, а не неограничен безплатен сървър. Използвай наличната безплатна квота и не включвай платено надвишаване. Без валиден платежен метод GitHub блокира използването след изчерпването ѝ. Ако вече имаш платежен метод, провери лимитите си преди стартиране. Спирай средата след преглед, за да запазиш квотата.

Официални източници: [квоти на GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces), [преглед чрез пренасочени портове](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace), [официален Node.js devcontainer](https://github.com/devcontainers/images/tree/main/src/javascript-node).

## Готов статичен ZIP — за бъдещо публикуване след одобрение

GitHub Actions вече запазва успешния build като artifact **dido-static-preview**, с валидност 7 дни. След успешна проверка отвори **Actions → Проверка на сайта → съответното изпълнение → Artifacts → dido-static-preview** и изтегли ZIP файла. Съдържа готовите HTML/CSS/JavaScript, шрифтове и снимки; не е необходим Node.js, за да се качи на статичен хостинг.

След изрично одобрение този ZIP може да бъде качен чрез **Cloudflare Pages → Direct Upload** за безплатен адрес `*.pages.dev`. Това вече е публикуване в интернет и не е извършено. За постоянния сайт с автоматични обновявания от Pages CMS препоръката остава Git интеграция, описана в `DEVELOPMENT.md`; Direct Upload е отделен вариант за ръчно качване.
